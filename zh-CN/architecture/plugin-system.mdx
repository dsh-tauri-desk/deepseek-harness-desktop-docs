Harness 插件可扩展宿主运行时、贡献工具并添加 UI 集成。桌面端提供生命周期管理和受控原生桥接。

{/* <!-- [插件宿主侧、客户端侧与 Tauri 桥](/images/zh-CN/plugin-architecture.webp) --> */}

## 职责

| 组件 | 职责 |
| --- | --- |
| Harness 宿主插件 | 注册工具、路由、系统上下文与生命周期钩子 |
| 客户端插件 | 为 Harness Web 应用添加面板或 UI 行为 |
| Tauri 桥插件 | 向嵌入客户端暴露获准的桌面命令和事件 |
| 桌面管理器 | 安装、升级、移除、修复并报告插件状态 |
| Profile | 持有自身的插件声明与配置 |

## 内部插件生命周期

Harness 启动前，桌面工作流确保活动 Profile 存在必需的第一方集成。声明缺失或不一致时，
从应用内置副本恢复，使原生设置与面板功能在更新中断后仍可使用。

可选预设和社区插件遵循常规安装、升级和卸载流程。Windows Minimal 修复插件在选择后从 GitHub 获取，并非内置源码。

## 通信路径

1. 嵌入式 Harness 客户端调用客户端插件暴露的集成。
2. 插件通过桌面桥发送结构化请求。
3. Tauri command 验证操作并调用对应 Rust service。
4. 结果或生命周期事件返回客户端并更新面板状态。

<Warning>
  安装插件就是安装代码。Profile 范围只能避免配置冲突，不能阻止恶意文件、进程、凭据或网络访问。
  请审查第三方源码，并尽量固定可信版本。
</Warning>

用户操作请参阅[插件](../guides/plugins)。
