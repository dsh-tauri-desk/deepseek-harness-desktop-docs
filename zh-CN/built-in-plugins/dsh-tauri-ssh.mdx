在**设置 → 服务器**管理远端机器。`dsh-tauri-ssh` 默认关闭，启用后才建立连接。

{/* <!-- [SSH 服务器设置、连接状态与远端窗口入口](/images/dsh-tauri-ssh.webp) --> */}

## 连接机器

1. 启用 SSH，选择 `~/.ssh/config` 别名或**添加机器**。
2. 检查主机、用户和 SSH 端口；按需设置远端端口、Profile 或启动命令。
3. 点击**测试**或**连接**，查看握手、启动、探测等进度与日志；连接成功且桌面桥可用时，点击**打开**进入远端窗口。
4. 连接失败或断线时按配置自动重试，界面显示重试倒计时；点击**断开**可停止重试。
5. 在发起端选择**同步到远端**，确认目标机器与勾选项。远端会话只显示提示，不在远端再次发起同步。

机器可设置标识颜色，并可选择同时着色边框。普通浏览器没有桌面桥时，不显示原生远端窗口的**打开**入口。

| 默认项 | 值或行为 |
| --- | --- |
| SSH / 远端 Web 端口 | `22` / `3080` |
| 远端 Profile | `remote` |
| 登录凭证 | 本机 SSH agent、`IdentityFile` 与默认密钥；可设置私钥口令或密码回退 |
| 手动机器与配置别名 | 同 ID 的手动机器优先 |
| 桌面内置插件 | 连接时尝试自动同步；不在手动同步列表中 |
| 第三方插件 / Skills | 远端执行 `dsh plugin add` / 写入 `~/.dsh/skills` |

## 单向同步到远端

- 连接时尝试同步桌面内置插件；失败时可降级为远端原生 UI，而不是保证完整桌面界面。
- 手动同步从当前 Profile 的第三方依赖和用户级 Skills 生成预览，默认选中可同步项；选择已连接的目标机器后再确认。
- 插件支持 npm 与 Git 安装来源；`file:`、`link:`、`workspace:` 和 HTTP URL 依赖标为不可同步，不会复制本机依赖目录。
- Skills 读取 `$DSH_HOME/skills`（`dsh`）与 `~/.agents/skills`（`agents`）的直接子目录，均写入远端 `~/.dsh/skills`。这是单向传输，不是双向同步；同名文件可能覆盖，先核对目标。
- 结果按项显示成功、失败与输出，可只重试失败项。同步插件还可能复制本机构建放行配置，或为安装输出提示的依赖放行构建并重试；只同步可信代码。

## 远端未安装 Harness

使用**一键安装 dsh**下载并部署到远端 `~/.dsh-desktop`，随后自动连接。有可信摘要且远端具备摘要工具时会校验下载内容；缺少条件时会记录警告并继续，不能视为始终完成校验。

| 自动安装平台 | 发行方式 |
| --- | --- |
| Linux x64 | 预打包 ZIP |
| Linux arm64 | npm 包，在远端安装依赖 |
| macOS Intel | 预打包 ZIP |
| Windows / macOS Apple Silicon | 不支持此自动安装流程 |

安装流程可能将本机 `.env` 中的 `DEEPSEEK_API_KEY` 与可选 `DEEPSEEK_BASE_URL` 写入远端 `~/.dsh/.env`；已有远端密钥不会被覆盖。检查安装结果，无本机密钥时在远端模型页配置。

## 数据与安全

- 机器配置（含已保存凭据）：`$DSH_HOME/ssh/machines.json`。
- 首次连接自动记录主机指纹：`$DSH_HOME/ssh/known-hosts.json`；后续不匹配会拒绝连接。
- 未设置 `DSH_HOME` 时使用 `~/.dsh`；宿主 API 前缀为 `/api/desktop/dsh-tauri-ssh`。原生桌面桥仅转发白名单内的这些接口到本机 Harness 服务。
- 远端 Web 服务通过 SSH 隧道访问，不需要将 Web 端口暴露到公网。

<Warning>
  首次指纹记录不等于预先验证服务器身份。仅连接可信机器；同步与安装会修改远端文件、执行代码，并可能复制 API 密钥。不要分享机器状态文件。
</Warning>
