`dsh-tauri-mobile-ui` 是独立的内置客户端插件，为触控型设备提供偏好快捷入口和精简布局；桌面设置侧栏仍由 [`dsh-tauri-ui`](./dsh-tauri-ui) 负责。

{/* <!-- [移动设备上的主题、语言选择与官方设置入口](/images/dsh-tauri-mobile-ui.webp) --> */}

## 使用移动偏好入口

- 在设置入口处直接选择浅色 / 深色主题与已注册的界面语言。
- 点击齿轮打开官方设置对话框；不新增一份设置数据或原生 Configuration 页面。
- 可用时，在插件加载后将会话视图一次切换为 `standard`；不是持续锁定视图模式。

## 精简布局

| 区域 | 移动设备上的调整 |
| --- | --- |
| 输入区 | 隐藏桌面 dock 工具区。 |
| 会话与页面顶部 | 隐藏部分标题、工具栏和回合错误代码显示。 |
| 消息区 | 调整滚动内边距，让用户消息可使用完整宽度。 |

## 生效条件与边界

- 通过浏览器输入能力判断设备：`(hover: none)`、`(any-pointer: coarse)` 与 `(any-hover: none)` 必须同时匹配，不只看窗口宽度或设备名称。
- 桌面浏览器仅缩窄窗口，不保证出现移动偏好入口；连接鼠标等输入设备也可能改变判断结果。
- 依赖 Harness 的设置、主题、语言和会话视图能力；不可用的入口不代表插件创建了替代设置服务。
- 当前发布版不提供手势侧栏。这个插件也不把 Web 页面变成独立的原生移动应用。
