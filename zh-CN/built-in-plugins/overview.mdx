## 分发与权限

- 清单以当前桌面 `plugins.built-in` 为准；旧 Running Changes 不再属于内置集合。
- 社区预设另行安装；扩展面板有可用的官方插件管理页时将其置于首位。可选市场是独立页签，仅在桌面 iframe 中且市场服务可渲染时显示。
- 内置插件可在设置中停用，停用前会提示风险。
- “内置”不提供额外操作系统沙箱。Harness 与插件仍可执行本地代码。
