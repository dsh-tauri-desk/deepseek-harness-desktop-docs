开始任务前，先配置至少一个模型供应商。模型设置位于嵌入的 Harness 界面，不是桌面端的**配置**对话框。

</Frame>

## 添加 DeepSeek

<Steps>
  <Step title="打开模型设置">
    在 Harness 侧边栏打开**设置 → 模型**。桌面端通过内置 [DSH Tauri Model](../built-in-plugins/dsh-tauri-model) 扩展这一页面。
  </Step>
  <Step title="保存凭据">
    在 DeepSeek 卡片输入来自 [DeepSeek 开放平台](https://platform.deepseek.com/) 的 API 密钥并保存。
  </Step>
  <Step title="选择模型并测试">
    回到会话输入区，选择可用模型和工作区，发送一个小型任务，例如概括仓库结构。若失败，先检查凭据、余额、端点和模型名称。
  </Step>
</Steps>

<Warning>
  不要把 API 密钥放入聊天消息、仓库、截图或 Issue。模型请求会把所需上下文发送给你选择的供应商；处理敏感代码前确认其隐私政策与数据范围。
</Warning>

## 其他供应商与自定义端点

| 入口 | 需要准备 |
| --- | --- |
| **添加供应商** | 已安装的供应商插件、对应凭据和可用模型 |
| **添加自定义供应商** | 稳定的小写 Provider ID、基础 URL、协议、凭据和至少一个模型 |

按端点支持情况配置上下文长度、输出上限、图片输入和思考模式；不要给不支持的模型启用这些能力。本地或公司网关的兼容选项见 [DSH Tauri Model](../built-in-plugins/dsh-tauri-model)。

上游供应商语义见[模型配置指南](https://deepseek-harness.github.io/deepseek-harness/guide/providers)。接下来了解[桌面端与 Harness 界面](../guides/interface)。
