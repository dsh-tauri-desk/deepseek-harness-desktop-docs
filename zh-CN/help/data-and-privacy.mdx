Harness 默认监听本机回环地址，桌面端嵌入其 Web 界面。本地保存数据不代表全程离线：模型、插件、工具和更新都可能联网。

## 数据位置

| 数据 | 正式版位置或边界 |
| --- | --- |
| Harness 用户数据 | 默认 `~/.dsh`；正式版可遵循 `DSH_HOME` |
| 档案配置、插件与补丁 | `$DSH_HOME/profiles/<id>`；首次安装使用 `tauri`，`web` 为回退档案 |
| 会话与工作区记录 | 位于 Harness 数据中的档案外目录；切换档案不隔离全部历史 |
| 仓库文件与 Git 工作树 | 你选择的工作区目录，不属于档案备份 |
| 默认托管运行时与依赖 | 应用数据中的 `runtime/`、`dependencies/`；内核为 `dependencies/dsh/` |
| 桌面设置 | 应用数据中的 `.store.dat` |
| Harness 服务日志 | 应用数据中的 `logs/dsh-web.log` |
| 档案备份 | `$DSH_HOME/.backups/`，内容仅覆盖活动档案目录 |
| 服务地址 | 首选 `http://127.0.0.1:3080`，占用时可能使用其他端口 |

从桌面**配置 → 应用**打开实际数据目录，不要仅凭目录名称推断正在使用的环境。

## 数据目录迁移

非 Debug 构建可在**配置 → 数据**中更改数据目录；Windows 安装器也可选择位置。

- 迁移依次复制、校验文件数与字节数、把旧目录改名为 `<旧目录>.moved-<时间戳>`，最后重写用户级 `DSH_HOME`；不会删除原数据。
- 先完成任务并关闭使用相同目录的其他客户端；桌面端会停止本机 Harness 后迁移。校验不完整会报 `DATA_DIR_COPY_INCOMPLETE`。
- 可回滚；当前目录非空时会先改名为 `<目标目录>.current-<时间戳>`。
- 开发构建固定使用 `~/.dsh.dev` 并忽略 `DSH_HOME`，不能迁移。
- 已打开的终端需重启才能使用新路径。

## 备份与恢复

1. 在**配置 → 档案**为活动档案创建备份；默认排除凭据，选择包含后按敏感文件保管。
2. 优先**还原为新档案**并验证，不要直接覆盖当前环境。
3. 另行备份工作区、未提交修改和需要保留的完整 Harness 数据。

### 恢复导出（包含会话）

- 入口：**配置 → 档案 → 备份 → 恢复导出（包含会话）**。先完成任务并关闭使用相同数据目录的其他桌面端、CLI 和网页客户端；导出后本机 Harness 保持停止。
- 导出包含所有档案、会话与共享存储，保存为应用数据 `recovery-backups/` 下的 `data.tar.zst` 与 `README.txt`；应用数据位于 `DSH_HOME` 内时会拒绝导出。
- 排除 `node_modules`、`.backups`、`.plugin-backups` 与 `.harness.pid`；遇到链接或联接会报错，归档不会自动裁剪。
- 恢复时按 `README.txt` 解压到新的空目录并检查数据，再安装匹配内核的依赖；**档案还原按钮不适用于此归档**。

<Warning>
  档案备份不包含档案外会话；恢复导出不包含外部工作区。即使未勾选凭据，其他配置也可能含密钥。私密保管归档，并复制到其他设备防范磁盘故障。
</Warning>

## 联网与远程访问

| 操作 | 网络与信任边界 |
| --- | --- |
| 首次安装、更新 | 下载运行时、内核与工具，访问发布源或回退来源 |
| 模型请求 | 向所选供应商发送请求与必要上下文；先确认其数据政策 |
| 插件安装与运行 | 安装时访问 npm/GitHub；运行时可执行本地代码并访问远程服务 |
| 应用代理 | **配置 → 应用 → 代理地址**支持 `http`、`https`、`socks5`、`socks5h`，用于桌面下载、更新和插件元数据；本机连接直连，不代表全部模型或插件流量 |
| 远程使用 | 优先使用 [SSH 隧道](../built-in-plugins/dsh-tauri-ssh)，不要直接暴露公网 |

桌面端没有 LAN 设置。打包内核仅在 `DSH_PKG_ALLOW_LAN=1` 时放行局域网监听；这不替代上游认证、访问令牌或工具权限，主机信任也不是认证。

<Warning>
  Profile、工作区和 Git 工作树都不是操作系统沙箱。处理不可信代码或插件时，使用独立用户、容器或虚拟机、最小权限凭据，并审查工具授权。不要在聊天、截图、日志或 Issue 中泄露密钥与私人数据。
</Warning>

## 开发环境隔离

- Debug 强制使用 `~/.dsh.dev`，忽略继承的 `DSH_HOME`。
- 默认托管运行时与依赖位于应用数据的 `dev/runtime/`、`dev/dependencies/`；内核为 `dev/dependencies/dsh/`。
- 日志为 `dev/logs/dsh-web.dev.log`；设置为应用数据根目录中的 `.store.dev.dat`。
- 首选端口为 Debug `3081`、正式版 `3080`；均可能回退到其他可用端口。
