## 应用

| 设置或状态 | 用途与生效方式 |
| --- | --- |
| 服务地址与连接状态 | 查看当前实际地址；默认本机访问，首选端口 `3080` |
| 端口 | 保存后按提示重启 Harness；占用时可能使用其他可用端口 |
| 内存上限 | 自动管理或设置 Harness 的 Node.js 堆上限；修改需重启服务 |
| 语言与界面缩放 | 调整桌面界面，缩放范围 `50%–200%` |
| 命令行集成 | 正式版默认启用托管 `dsh` shim；修改后打开新终端 |
| 开机启动与关闭行为 | 默认关闭窗口隐藏到托盘，可改为退出应用 |
| 版本、数据目录与日志 | 查看运行组件，打开目录或复制排障信息 |

桌面端不提供 LAN 设置；打包内核的局域网放行不替代认证或权限，见[数据、隐私与安全](../help/data-and-privacy)。CLI 的 PATH 和 shell 配置影响见[命令行集成](./cli-integration)。

## 外观

| 设置 | 用途与生效方式 |
| --- | --- |
| 配色 | `default`、`nord`、`solarized`、`forest`、`amber`、`github`、`github-dimmed`、`github-high-contrast` 八种 |
| 终端模式 | 隐藏侧栏并保留原字体；左上角侧栏按钮可重新展开 |
| 透明与不透明度 | 背景不透明度 `20%–100%`；切换原生透明模式需完全退出并重开，关闭到托盘不够 |
| 会话区域保持不透明 | 透明模式下仅让外围区域透出桌面，会话与右侧区域保持不透明 |

## 数据、网络与进程

| 入口 | 常用操作 |
| --- | --- |
| **配置 → 数据** | 查看占用、预检目标目录、迁移或回滚；非 Debug 构建可用，Debug 固定 `~/.dsh.dev` |
| **配置 → 应用 → 代理地址** | 支持 `http`、`https`、`socks5`、`socks5h`；保存后对新的桌面下载、更新与插件元数据请求生效 |
| **帮助 → 任务管理器** | 查看本机应用、Harness 与子进程的名称、PID、CPU、内存和运行时长；默认每 2 秒刷新 |
| **配置 → 档案 → 备份** | 档案备份或包含会话的恢复导出；两者的恢复方式不同，见[数据、隐私与安全](../help/data-and-privacy) |

- 代理留空沿用系统或环境代理，本机回环连接保持直连；不要据此假定模型或插件的全部网络流量都走该代理。
- 任务管理器只能结束 Harness 子进程，也可重启 Harness；两者会中断相关任务。系统独立托管的 WebView 进程可能不在列表中。

## 档案

首次安装使用 `tauri` 档案；`web` 是内置回退档案。档案管理配置、插件和补丁，不提供操作系统隔离。

1. 在**档案**面板创建或克隆档案，使用简短的 ASCII 名称。
2. 选择目标档案并确认切换，按提示重启服务。
3. 在修改或删除前创建备份；优先使用**还原为新档案**测试恢复。

<Warning>
  重置、删除或覆盖还原会改变档案数据。先备份，确认恢复范围；档案备份不能替代工作区和完整会话数据备份。
</Warning>

## 插件与核心

| 面板 | 常用操作 |
| --- | --- |
| **插件** | 查看来源、版本和错误；从仓库或本地目录安装、升级和移除可选插件；停用内置插件需确认风险 |
| **核心** | 下载兼容版本、选择来源并切换；桌面端和 Harness 内核分别更新 |

不要把删除档案或内核作为第一步排障。先复制日志，再确认问题属于依赖、插件、服务还是模型。

版本与档案说明见 [Profile 与内核](./profiles-and-cores)；存储位置见[数据、隐私与安全](../help/data-and-privacy)。
