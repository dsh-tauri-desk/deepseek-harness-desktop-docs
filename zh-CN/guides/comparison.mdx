## 项目定位

| 项目 | 桌面技术 | 主要取舍 |
| --- | --- | --- |
| 本项目（dsh-tauri） | Tauri 2 + React；独立 Harness 服务 | 第一方桌面增强、运行时管理；社区插件按需选择 |
| anywhere-labs/dsh-desktop | Electron；桌面本身是 DSH/Cordis 插件 | 插件式组合、Profile 向导、Agents Anywhere 手机控制 |
| dataelement/dsh-desktop | Electron | 本地优先、可移植 Agent preset、PPT/Office 与手机配对桥 |
| DeepSeek 官方桌面端 | Electron；内置完整 Harness Web UI 与 Host | 官方公共预览；桌面与内核同步更新，插件按需启用 |

框架名称不是性能排名；安装体积、内存与响应速度还取决于运行时和插件，本文没有统一基准测试。

## 管理、插件与恢复

本项目依据 v0.22.1 与 `main@618a2edd`；竞品按上述发布标签核对。官方列区分公共预览与当前桌面源码。

| 比较项 | 本项目 | anywhere-labs | dataelement | DeepSeek 官方 |
| --- | --- | --- | --- | --- |
| Profile / 运行时 | 原生 Profile；多内核切换、复用本地 `dsh`、CLI 集成 | Profile 向导/切换；固定 Harness | 保留 Profile 数据；固定 Harness | 专用 `desktop` Profile；内核随桌面更新，可选 CLI 注册 |
| 插件策略 | 12 个第一方内置；`dshmarket` 等为可选预设 | 桌面即插件；内置社区市场 | Harness 插件；第三方插件按需安装 | 共用 Harness 插件管理器；Creator mode 创建插件 |
| 特色管理入口 | 扩展首 tab 复用可用的官方插件管理器；Skills/来源与 MCP 管理 | Profile 设置与插件 CLI | `.dshpreset` 导入/导出、模型供应商、PPT/Office、工作台市场 | 插件管理、运行轨迹与开发者工具 |
| Worktree / 定时任务 | 会话 Git Worktree；定时执行与运行历史 | 未确认 | 未确认 | Worktree 未确认；定时任务需启用插件，非默认开启 |
| 插件故障恢复 | 定位问题插件、离线移除；独立安全档案 | 恢复助手 | 故障诊断；非破坏性 Safe Mode | 原生恢复对话框；禁用第三方插件、备份 Profile patch 后重启 |

- 本项目内核推荐 `0.2.0-rc.2`，最低 `0.1.5-rc.1`；anywhere 三种已发布包均固定 `0.2.0-rc.2`。当前 `master` 的 Beta/Next 清单已改为 `0.2.1-alpha.1`，不代表上述安装包已升级。
- dataelement v0.11.0 使用 `0.2.0-rc.2`；工作台功能（含市场）默认关闭，需在「常规」中启用；Windows/macOS 捆绑 Python Office 创作运行环境。
- 本项目当前内置包含 `dsh-tauri-mobile-ui` 与 `dsh-tauri-notification`；原生通知不再是 Beta 独有功能。
- 官方当前桌面源码清单为 `0.2.1-alpha.1`；下载页的 `latest` 链接未标安装包版本，本页不将源码版本当作安装包版本。桌面与 CLI 共用产品数据，但插件启用状态与可执行依赖隔离，不等于多内核切换。

## 远程入口的区别

| 机制 | 本项目 | anywhere-labs | dataelement | DeepSeek 官方 |
| --- | --- | --- | --- | --- |
| SSH 远程主机 | 内置 `dsh-tauri-ssh`；连接远端 `dsh web`，经回环隧道访问 | 未确认 | 未确认 | 未确认 |
| 手机续接 | 移动 UI 适配已内置；内置配对桥未确认，可选第三方桥另核对 | Agents Anywhere（2.0.9 起） | 独立配对桥：LAN / 临时公网隧道 | 未确认 |

- SSH 在远端主机运行 Harness；手机桥续接桌面会话。`dsh-tauri-mobile-ui` 是界面适配，不等于原生手机安装包或配对/公网桥。
- anywhere 的浏览器打开不改变监听范围；另行开启 LAN 会暴露无鉴权入口，仅用于完全可信网络。
- dataelement 的 Harness 仍监听随机回环端口；公网桥需配对密码，断开手机会使移动会话失效。

## 如何选择

- 需要多内核管理、第一方面板、Worktree、定时任务或 SSH 主机连接：先看本项目，并确认安装渠道与普通/Bundle 资产。
- 需要插件式桌面与 Agents Anywhere：看 anywhere；更重视可移植 preset、PPT/Office 和配对手机桥：看 dataelement。
- 希望直接使用官方 Harness 桌面预览：看官方下载页，先确认操作系统与架构，再按需启用插件。

<Warning>
  Harness 与插件可执行本地代码。Profile、Worktree、Safe Mode 和插件保护不等于 OS 沙箱。
  审查安装来源、插件与网络暴露方式；不可信任务应使用系统级隔离。
</Warning>
