---
title: Profile 与内核
description: 使用 Profile 隔离 Harness 配置，并选择活动内核。
---

Profile（档案）决定配置、插件和补丁环境；内核决定本地服务运行哪个 Harness 版本。两者都不是操作系统沙箱。

## 选择档案

首次安装创建并使用 `tauri`，`web` 是内置回退档案。其他档案位于 `$DSH_HOME/profiles/<id>`；会话数据位于档案外，不能假定切换档案会隔离全部历史。

1. 在桌面**配置 → 档案**创建或克隆档案。
2. 暂停活动任务，记录工作区和未提交修改。
3. 切换档案并按提示重启，确认模型和插件可用。

<Frame>
  <img src="/images/zh-CN/profiles-cores-profile.png" alt="Profile 档案设置" />
</Frame>

删除、重置或覆盖还原前先备份。档案备份只覆盖当前档案范围，不包含工作区或档案外的完整会话数据；凭据默认不包含，勾选后需按敏感文件保管。

## 选择内核

<Frame>
  <img src="/images/zh-CN/profiles-cores-core.png" alt="Harness 内核版本与下载操作" />
</Frame>

| 来源 | 用途 |
| --- | --- |
| 自动 | 优先使用兼容的本地 CLI 内核，否则使用托管内核 |
| Local | 使用桌面端检测到且兼容的本地 Harness |
| App | 使用桌面端下载的预构建发行版 |

当前推荐内核为 `0.2.0-rc.2`，最低接受版本为 `0.1.5-rc.1`。版本列表仍由桌面端和插件兼容规则筛选，不保证任意上游版本都能使用。

## 切换或升级前

1. 完成或暂停活动工具任务，备份档案并检查仓库状态。
2. 选择兼容内核；若提示使用独立的版本档案，按提示操作。
3. 等待服务重启，确认会话连接、模型和插件状态。
4. 出现错误时先保留日志，尝试已安装的兼容版本，不要先删除数据。

<Warning>
  档案和插件仍以进程获得的权限运行。测试不可信插件需要独立用户、容器或虚拟机等真正的隔离环境。
</Warning>
