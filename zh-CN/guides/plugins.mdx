插件可以添加工具、面板和系统集成。先区分内置插件与可选社区插件，再决定安装或恢复方式。

## 插件类型

| 类型 | 来源与控制 |
| --- | --- |
| 内置 | 11 个第一方桌面集成，由桌面端确保安装；不是社区插件合集 |
| 预设 | 向导提供的 6 个可选社区插件，经确认后下载，可更新或移除 |
| 其他社区插件 | 手动或通过市场安装；先检查来源、兼容性与执行能力 |

- 当前清单和各插件操作见[内置插件概览](../built-in-plugins/overview)。
- `dsh-tauri-experimental` 是默认关闭的可选实验包，不计入这 11 个插件。

## 可选预设

| 显示名称 | 包 ID | 初始选择 |
| --- | --- | --- |
| DSH Market | `dshmarket` | 推荐，默认选中 |
| DSH Better Sidebar | `dsh-better-sidebar` | 推荐，默认选中 |
| DSH Rewind | `dsh-rewind-plugin` | 推荐，默认选中 |
| DSH Bridge | `@wenbin_wb/dsh-bridge` | 推荐，未选中 |
| DSH IM | `@xmanrui/dsh-im` | 推荐，未选中 |
| Billion Context | `billion-context` | 可选，未选中 |

预设不计入内置插件数量，也不保证适合每个任务。安装前检查维护状态、网络依赖和数据处理方式。DSH Market 等预设通过首次运行向导或插件管理的专用安装流程安装，不是向聊天 Agent 发出安装请求。

## 安装、更新与恢复

1. 打开桌面**配置 → 插件**，确认活动档案、来源、版本和错误信息。
2. 安装可信插件，或升级、移除不再需要的可选插件。
3. 按提示重启 Harness，确认插件加载成功。
4. 操作中断时使用面板显示的恢复入口；内置插件缺失时由桌面端修复。

推荐 Harness `0.2.0-rc.2`，最低接受 `0.1.5-rc.1`；实际可选内核和插件版本仍受兼容规则限制。启动异常先保留日志，再使用明确的恢复入口，见[故障排除](../help/troubleshooting)。

<Warning>
  安装插件就是安装可执行的本地代码。Profile 不提供操作系统级沙箱；不要把“内置”“推荐”或“开源”当作无风险保证。
</Warning>

开发者可阅读[插件系统架构](../architecture/plugin-system)。
