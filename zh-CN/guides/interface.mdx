窗口内的 **Harness 工作区**负责 Agent 任务；原生**桌面壳**负责本地服务和系统集成。先按任务选择入口。

</Frame>

## 常用入口

| 要做什么 | 去哪里 |
| --- | --- |
| 选择工作区、创建会话、发送任务 | Harness 侧边栏和输入区 |
| 切换模型、管理工具、Skills 或 MCP | Harness **设置** |
| 查看工具活动、审批和结果 | 当前 Harness 会话 |
| 配置应用、档案、插件或内核 | 桌面标题栏 **配置** |
| 复制运行日志 | **帮助 → 运行日志** |
| 检查桌面更新 | **帮助 → 检查更新** |
| 查看桌面版本和源码 | **帮助 → 关于 Desktop** |

顶部栏还提供侧边栏、后退、前进和窗口控制；macOS 可使用原生菜单与交通灯按钮。

## 桌面配置

<Frame>
  <img src="/images/zh-CN/desktop-settings.png" alt="包含调试、档案、插件与核心入口的桌面配置对话框" />
</Frame>

| 面板 | 用途 |
| --- | --- |
| **应用** | 服务地址和状态、端口、内存、缩放、CLI 集成、开机启动、关闭行为、版本与数据目录 |
| **档案** | 创建、克隆、切换、备份或删除 Harness 配置环境 |
| **插件** | 检查已安装插件、错误与恢复操作，管理可选插件 |
| **核心** | 下载、切换或移除兼容的 Harness 内核 |

<Note>
  默认关闭主窗口会隐藏到托盘，服务继续运行；可在**应用**面板改为退出应用。档案分离配置与插件，不是操作系统沙箱。
</Note>

具体选项见[桌面设置](./settings)；任务流程见[工作区与会话](./workspaces-and-sessions)。
