DeepSeek Harness Desktop 管理本地 Harness 服务、运行时、档案和插件。你无需手动安装 Node.js、pnpm 或 Docker；首次启动通常需要联网下载依赖，开始任务前还需配置模型供应商。

## 分清两个设置入口

| 入口 | 管理内容 |
| --- | --- |
| Harness **设置** | 模型、工具、Skills、MCP 和任务相关配置 |
| 桌面端 **配置** | 应用行为、档案、插件、Harness 内核和更新 |

首次安装使用桌面档案 `tauri`。正式版默认启用 [CLI 集成](./guides/cli-integration)，重新打开终端后可运行 `dsh --help`。

<Warning>
  Harness 和插件可以执行本地代码。只使用可信仓库和插件，并审查工具权限。档案和 Git 工作树不是操作系统沙箱；处理不可信代码时使用独立用户、容器或虚拟机等真正的隔离环境。
</Warning>
