我们制作 DeepSeek Harness Desktop，是为了提供一套可维护的本地桌面工作流，而不是替所有用户选出唯一的客户端。

<Note>
  这里说明项目取舍，不给社区项目排名。不同客户端适合不同需求，具体事实见[桌面客户端对比](./guides/comparison)。
</Note>

## 项目取舍

| 原则 | 对使用者意味着什么 |
| --- | --- |
| 非商业捆绑的开源组织 | 不强制绑定与 Harness 无关的商业服务、模型渠道或推广内容；公开源码、讨论和发布流程 |
| 小而可维护的默认集 | 内置第一方桌面集成；社区预设明确可选，不以预装数量代表质量 |
| 本地服务与桌面壳分开 | Tauri 使用系统 WebView；Harness 作为独立服务运行，桌面端与内核分别更新 |
| 先完善基础流程 | 优先处理安装、启动、档案、更新、日志和恢复，再增加功能 |
| 可验证的承诺 | 依据当前源码和发布资源描述能力，明确平台限制，不把规划写成已交付 |

“非商业捆绑”不排斥个人或组织参与，也不否定其他开源模式；它约束的是本项目的产品边界。

## 体验目标，不是性能结论

我们希望逐步达到 Codex 桌面端所体现的产品完整度：功能、响应、稳定性、细节一致性和故障恢复。这是目标，不是已经达到的保证。

<Info>
  使用 Tauri 不自动意味着更快或更省内存。运行时、内核、插件、启动时间和交互响应都影响体验，需要实际测量。
</Info>

## 信任与边界

- 可选预设需要你确认安装，不属于内置插件数量。
- 档案只分离配置与插件环境，不提供操作系统级隔离。
- 上游和生态仍在变化；兼容性以桌面端提供的版本范围为准。
- 我们不以 Star、功能清单或未经测量的“更安全”“更轻”替代质量证据。

<Warning>
  Harness 和插件可以执行本地代码。减少默认捆绑不能消除不可信仓库、第三方插件或工具授权带来的风险。安装前检查来源，执行前审查权限。
</Warning>
