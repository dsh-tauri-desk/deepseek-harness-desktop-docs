Tauri 将 React 前端、Rust 后端和内置资源打包为原生安装程序；GitHub Actions 执行发布流程。

## 本地构建

按[开发环境](./setup)准备工具链后运行：

```bash
pnpm install --frozen-lockfile
pnpm build:plugins
pnpm typecheck
pnpm lint
node node_modules/vitest/vitest.mjs run --project unit
pnpm tauri build
```

`pnpm tauri build` 通过 `pnpm build` 先构建插件与前端，再编译并打包 Rust 应用。按[测试与质量检查](./testing)补齐 E2E 与 Rust 检查；平台包需要兼容系统及对应签名工具。

## 发布流程

[发布工作流](https://github.com/dsh-tauri/deepseek-harness-desktop/blob/main/.github/workflows/release.yml)由 `v*` tag、合并本仓库的 `release/*` PR 或手动触发；手动运行生成测试预发布。

1. 对齐 package、Cargo 与 Tauri 版本、发布说明和双语文档。
2. 完成前端类型检查、lint、三层测试与跨平台 Rust 检查。
3. 并行构建 Windows、两种 macOS 架构及 Linux x64 产物；验证签名、公证与安装行为。
4. 单一发布任务汇总成功产物；预发布标记为 prerelease，稳定版才更新 latest。

<Warning>不得在日志、文档、Pull Request 或 fixture 中暴露签名证书、公证凭据或更新密钥。</Warning>

当前公开版本只提供 Linux x64 产物；构建并验证对应产物前，不要声明支持 Linux ARM。
