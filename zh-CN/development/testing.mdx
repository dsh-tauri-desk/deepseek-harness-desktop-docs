开发期间运行最快的相关检查，提交 Pull Request 前完成完整前端与 Rust 测试。

## 前端检查

```bash
pnpm typecheck
pnpm lint
pnpm test -- --run
```

Vitest 覆盖前端逻辑和组件。测试应保持确定性，除非由测试明确管理生命周期，否则不要依赖正在运行的正式版服务。

## Rust 检查

在 `src-tauri/` 中：

```bash
cargo check
cargo test
```

CI 在 Ubuntu 22.04、macOS 14 和 Windows 上运行更严格的矩阵命令：

```bash
cargo test --all-features --locked
```

## 提交 Pull Request 前

- 为行为变化新增或更新测试。
- 确认未提交密钥、本机隐私路径或生成的应用数据。
- 涉及路径或端口时同时测试正式版和 Debug。
- 用户可见变化需同步两种文档语言。
