We build DeepSeek Harness Desktop to provide a maintainable local desktop workflow, not to choose one client for everyone.

{/* <!-- [DeepSeek Harness Desktop product principles and boundaries](/images/en/why.webp) --> */}

<Note>
  This page explains our choices, not a ranking of community projects. Different clients suit different needs; see the [desktop client comparison](./guides/comparison) for the facts.
</Note>

## Project choices

| Principle | What it means for you |
| --- | --- |
| An open-source organization without commercial bundling | No forced services, model channels, or promotions unrelated to Harness; public source, discussions, and release processes |
| A small, maintainable default set | First-party desktop integrations are built in; community presets remain optional, and plugin counts are not a quality measure |
| Separate local service and desktop shell | Tauri uses the system WebView; Harness runs independently, with separate desktop and core updates |
| Complete the basics first | Prioritize installation, startup, profiles, updates, logs, and recovery before adding features |
| Verifiable commitments | Describe current source and release artifacts, state platform limits, and keep plans separate from shipped features |

“No commercial bundling” does not exclude individuals or organizations or dismiss other open-source models. It defines this project's product boundary.

## An experience goal, not a performance claim

We aim to approach the product completeness demonstrated by Codex across functionality, responsiveness, stability, consistent details, and recovery. This is a goal, not a guarantee already achieved.

<Info>
  Tauri does not automatically make an app faster or more memory-efficient. Runtimes, the core, plugins, startup time, and interaction latency all affect the experience and need measurement.
</Info>

## Trust and boundaries

- Optional presets require your installation approval and do not count as built-in plugins.
- Profiles separate configuration and plugin environments, not operating system permissions.
- Upstream and the ecosystem continue to change; use the desktop's supported version range.
- Stars, feature lists, and unmeasured “safer” or “lighter” claims are not quality evidence.

<Warning>
  Harness and plugins can execute local code. Fewer default bundles do not remove the risks of untrusted repositories, third-party plugins, or tool authorization. Check sources before installing and review permissions before execution.
</Warning>
