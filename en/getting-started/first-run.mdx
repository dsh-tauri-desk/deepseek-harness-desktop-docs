First launch prepares the local Harness service, then loads its Web interface in the desktop window. Stay online and keep the app open during downloads and verification.

<Steps>
  <Step title="Prepare dependencies">
    The desktop checks for compatible runtimes and downloads managed Node.js, pnpm, and a prebuilt Harness core when needed. Supported downloads can use regional fallback sources.
  </Step>
  <Step title="Choose optional presets">
    The guide offers six community presets. DSH Market, DSH Better Sidebar, and DSH Rewind are selected by default; deselect or skip them and install later through plugin management. See [Plugins](../guides/plugins) for the full list.
  </Step>
  <Step title="Open Harness">
    First installation creates and uses the `tauri` profile. The service listens locally by default, with `http://127.0.0.1:3080` as its preferred address; it can use another available port if needed.
  </Step>
  <Step title="Configure a model">
    Add provider credentials in Harness **Settings → Models**, then select a model in the session and send a small test task.
  </Step>
</Steps>

## Current managed components

| Component | Current version or purpose |
| --- | --- |
| Desktop | `0.20.0-beta.1` |
| Harness core | Recommended `0.2.0-rc.2`; minimum accepted `0.1.5-rc.1`, still subject to compatibility rules |
| Node.js / pnpm | `22.22.0` / `11.7.0` |
| Built-in plugins | 11 first-party desktop integrations |
| Optional presets | Only community plugins you approve are installed; they do not count as built-ins |

## Verify setup

The window should show the Harness session interface. Release builds enable [CLI integration](../guides/cli-integration) by default; open a **new terminal** and run:

```bash
dsh --help
```

<Note>
  The desktop has no LAN toggle. LAN listening in the packaged core requires explicit opt-in with `DSH_PKG_ALLOW_LAN=1`; it does not bypass authentication or tool permissions. Prefer an [SSH tunnel](../built-in-plugins/dsh-tauri-ssh) for remote use, and do not expose the service directly to the public internet.
</Note>

See [Troubleshooting](../help/troubleshooting) if downloads or startup fail, or [Configure a model](./configure-model) for model setup.
