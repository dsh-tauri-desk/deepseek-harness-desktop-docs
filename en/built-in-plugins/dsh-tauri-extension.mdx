## Plugins

- Embeds the official Harness plugin manager and its installation and management capabilities, without a separate plugin catalog or configuration model.
- Hides the duplicate sidebar entry while the official page is available. If that capability is missing or withdrawn, the original entry remains or returns instead of an empty tab.
- A **Market** tab can appear when a renderable market service is available in the desktop iframe. It is absent when the service is missing or incompatible, not an independent community marketplace bundled with this plugin. See [plugin management](../guides/plugins).

## Skills

- Search, filter, enable, or disable skills; inspect content or open directories.
- Import GitHub skill repositories or add local skill directories.
- Edit skills from writable sources; check the target directory before deletion.
- **New skill** requires an available project workspace. It opens or reuses a blank session and prefills `/skill-creator ` without sending it.

## MCP

- Add, edit, enable, disable, or delete servers using a form or JSON, and inspect global and current-profile configuration sources.
- Import configuration from Claude Code or Codex. The check only tests command resolution or HTTP reachability; it does not guarantee a successful MCP protocol handshake.
- Restart the host when prompted after configuration changes. Restarting interrupts running turns and may lose unsaved input.

## Data and boundaries

- Custom skills live under `$DSH_HOME/skills/`; skill sources can point to local directories or imported GitHub repositories.
- MCP reads global and current-profile `cordis.patch.yml` files. Management actions default to writing the current profile.
- Host routes use `/api/desktop/dsh-tauri-extension`.
- Plugins, Skills, and MCP can trigger local code execution. Verify sources and permissions before importing.
