Download an installer for your platform and architecture. Standard installers download compatible runtimes and a prebuilt Harness core on first launch; you do not need to configure Node.js, pnpm, or Docker yourself.

## Choose a version and download

## Systems and installers

These are the actual `0.20.0-beta.1` release assets and system requirements:

| Platform | Requirements and architecture | Installer |
| --- | --- | --- |
| Windows | Windows 10+, WebView2; x64 | `.exe` / `_x64_en-US.msi` / `_x64_zh-CN.msi` |
| macOS | macOS 12+; the Web interface needs Safari 17.4+ capabilities; Apple Silicon / Intel | `_aarch64.dmg` / `_x64.dmg` |
| Linux | x64; WebKit2GTK 4.1 runtime | `.deb` / `.AppImage` |

Available architectures and installer types depend on the selected release's actual assets. Git features such as worktrees also require Git installed on your system.

On macOS, you can also use Homebrew:

```bash
brew install dsh-tauri/desktop/deepseek-harness
```

## Install and launch

1. Run the installer; allow file execution first if using AppImage.
2. Open **DeepSeek Harness Desktop** from the application menu.
3. Keep the app open and stay online while completing [First run](./getting-started/first-run).

Model requests, plugin installation, and updates may still need network access. Local execution does not mean an entirely offline workflow.

## Platform issues

<AccordionGroup>
  <Accordion title="Windows security prompt or missing WebView2">
    Confirm the installer came from the official Release. If WebView2 is missing, install Microsoft's WebView2 Runtime and retry.
  </Accordion>
  <Accordion title="macOS blocks first launch">
    Verify the download source, then allow the app in **System Settings → Privacy & Security**. Even when macOS meets the minimum version, check WebView compatibility too.
  </Accordion>
  <Accordion title="Black window on Linux Wayland">
    Try `.deb` first. If AppImage still shows a black window, try:
    ```bash
    WEBKIT_DISABLE_COMPOSITING_MODE=1 WEBKIT_DISABLE_DMABUF_RENDERER=1 GDK_BACKEND=x11 ./Deepseek*.AppImage
    ```
    See [Troubleshooting](./help/troubleshooting) for more startup, permission, and display issues.
  </Accordion>
</AccordionGroup>
