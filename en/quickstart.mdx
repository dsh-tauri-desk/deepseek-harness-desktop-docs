DeepSeek Harness Desktop manages the local Harness service, runtimes, profiles, and plugins. You do not need to install Node.js, pnpm, or Docker manually. First launch usually downloads dependencies; configure a model provider before starting a task.

## Know the two settings entry points

| Entry point | What it manages |
| --- | --- |
| Harness **Settings** | Models, tools, Skills, MCP, and task configuration |
| Desktop **Configuration** | Application behavior, profiles, plugins, the Harness core, and updates |

First installation uses the `tauri` desktop profile. Release builds enable [CLI integration](./guides/cli-integration) by default; open a new terminal to run `dsh --help`.

<Warning>
  Harness and plugins can execute local code. Use trusted repositories and plugins, and review tool permissions. Profiles and Git worktrees are not operating system sandboxes; use a separate user, container, or virtual machine for untrusted code.
</Warning>
